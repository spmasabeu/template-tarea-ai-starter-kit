# AI Starter Kit

Materiales base para trabajar tareas del curso con apoyo de IA sin perder trazabilidad.

## Guías

1. [00 - Setup](guides/00-setup.md): prepara cuentas, entorno local, base de datos y primera herramienta de IA.
2. [01 - AI Tools](guides/01-ai-tools.md): usa agentes con contexto, permisos mínimos, MCPs y prompts revisables.
3. [02 - Spec Workflow](guides/02-spec-workflow.md): transforma tareas ambiguas en specs, planes y validaciones chicas.
4. [03 - Git y Pull Requests](guides/03-git-pull-requests.md): trabaja con ramas, commits, PRs y revisión antes de mergear.
5. [04 - CI/CD y Render](guides/04-ci-cd-render.md): conecta checks automáticos, protección de `main` y deploy en Render.
