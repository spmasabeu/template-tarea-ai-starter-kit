# Gitflow minimo

## Ramas

- `main`: estable.
- `feature/<tema>`: nueva funcionalidad.
- `fix/<tema>`: correccion.
- `docs/<tema>`: documentacion.

## Commits

```text
tipo: resumen corto
```

Tipos:

- `feat`
- `fix`
- `docs`
- `test`
- `refactor`

## PR

1. Crear rama desde `main`.
2. Hacer cambio pequeno.
3. Correr checks.
4. Abrir PR con resumen y validacion.
5. Pedir revision.
6. Corregir feedback.
7. Fusionar cuando este aprobado.
