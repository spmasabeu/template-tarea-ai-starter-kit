# AGENTS.md

## Contexto del repo

- Este repositorio es un starter kit Rails para tareas asistidas por IA.
- Mantener cambios chicos, claros y fáciles de revisar.
- No guardar tokens, API keys ni credenciales en Git.

## Flujo esperado

- Leer `README.md` y la guía relevante en `docs/` antes de editar.
- Antes de modificar archivos, explicar brevemente qué se va a cambiar.
- Después de cambios de código, correr el chequeo más chico que valide el cambio.
- Si solo se edita markdown, revisar el diff.
- Para tareas no triviales, usar Spec Kit simplificado: `spec.md`, `plan.md`, implementación y review; no crear artefactos extra salvo que se pidan.

## Estilo

- Preferir soluciones simples y comandos reproducibles.
- Documentar solo lo que ayude a otro estudiante a continuar.
- Evitar cambios no relacionados con la tarea.
